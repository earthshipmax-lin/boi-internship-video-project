## 项目历史资料归档与恢复

[下载项目历史资料的十个分卷](https://github.com/earthshipmax-lin/boi-internship-video-project/releases/tag/project-archive-2026-10-27)。归档含原视频工程的素材、历史试片、配音及制作记录；各 ZIP 可单独解压，每卷 `_archive_manifest.json` 记录该卷文件路径、大小和 SHA-256。将各卷解压到同一个空文件夹，可按原 `video` 工程相对路径还原；同名文件若出现冲突，应先对照清单核验，切勿覆盖现有资料。

十卷上传后，GitHub 的附件 SHA-256 和大小均与打包文件一致；第一卷已重新下载，并对其中 73 个文件逐项核验。其余九卷暂未逐卷下载恢复测试。node_modules、模型缓存、venv、vendor、Git 元数据和新建归档工作目录未收录；另外，项目根目录其他业务资料也不在这十卷的范围内。

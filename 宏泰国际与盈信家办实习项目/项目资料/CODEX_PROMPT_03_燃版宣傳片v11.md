**史詩感 ≠ 快剪燃**：史詩靠的是**尺度、重量、留白、音樂的推進**。鏡頭要慢而重，字要大而穩，每個重點之前要有蓄力。不要抖音式快切、不要閃爍震屏。

## 2. 視覺語言：史詩感怎麼落地

- **尺度**：大量使用遠景與「從微小到巨大」的推拉：一粒種子→大樹；一個點→全球版圖。主標字佔畫面高度 30–45%，像紀念碑。
- **重量**：鏡頭運動慢（緩推、緩升、慢速視差），數字落定用重而短的 ease-out，配低頻 impact；禁止彈跳／elastic。
- **光**：深色底 #0B2E45 為主，像黎明前的天幕；卡布里藍 #2A85A8 作冷光，米白 #F4EEE2 作主字；朱砂 #B9653F 只在「1997」與片尾各點一次。允許**柔和體積光／地平線光帶**營造黎明感，禁止鏡頭光斑、粒子雨、廉價故障特效。
- **簡單層**：每鏡只有一個主角（一個數字、一句話、一棵樹）。
- **複雜層**：主角背後低對比精密細節：年輪同心線、經緯網格、城市連線、Logo 牆、牌照編號掃描。暫停細看經得起，正常播放不搶主角。
- **生長母題貫穿全片**：種子→年輪擴張→樹冠覆蓋全球→v10 原版 82 葉大樹生長收尾。
- 1920×1080／30fps，總長以 BGM 實測為準，目標 65–70 秒。片尾 Logo 靜止至少 2 秒。

## 4. 聲音

**配音**：只透過使用者 Chrome 已登入的 MiniMax 網頁，不找 API 憑證、不購買升級。speech-2.8-hd／Cantonese／低沉渾厚男聲（電影預告旁白感，沉穩不喊）／speed 0.95–1.0／Calm、Fluent。旁白原文見 `video/v11_燃版_生成清單.md`（共 S1–S8）。
**先只生成 S8 一段＋3 版 BGM，停下給使用者和老闆試聽，確認後再生成 S1–S7**。記錄點數變化。原 MP3 存 `video/qa/v11/minimax-source/`。

**BGM**：MiniMax Music 純音樂史詩管弦（90 BPM，低起→推進→34s 打開→52–64s 高潮→長尾音），提示詞見生成清單，存 `video/public/music/v11/`。

**混音**：旁白 1 倍速，不變調、不裁尾、不加速塞時長；人聲時 BGM ducking 約 -8 dB（史詩片音樂要保有存在感）；旁白可加極輕的大空間殘響；成片約 -14 LUFS，峰值 ≤ -1 dBTP。用 librosa/ffmpeg 偵測 onset 與段落，寫入 `src/config/beats-v11.json` 作切鏡時間表。

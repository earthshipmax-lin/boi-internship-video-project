## 3. 地圖鏡：重畫航線 + 修城市位置

### 3.1 現有缺陷（已核對 `world-v12.json`）

1. **香港與深圳幾乎重疊**：投影為等距圓柱仿射，`1°經度 ≈ 4.56px`、`1°緯度 = 4.4px`。兩地實際相距約 30km，投影後僅 **0.5–1px**，畫面上黏成一點。這是「地點不夠準確」的根本原因，不是標籤位置問題。
2. **航線是折線**：`routes` 為預先算好的座標陣列，以 `L` 連接，弧線由短直線拼成，放大可見稜角。
3. **紐約段橫切歐亞**：起點與控制點未按大圓航線計算，線條穿過大陸而非沿弧飛越。

### 3.2 城市位置：改為大圓 + 局部放大鏡

**主圖**
- 保留現有等距圓柱投影（`x0=140, width=1640, lon∈[-40,320], y_at_80=320, 4.4px/°`），不改投影。
- 香港、深圳在主圖上**合併為一個點**（香港座標），標籤只寫「香港」。
- **刪除主圖上單獨的「深圳」標籤**——兩地在這個比例下本就不可能分開，硬標只會疊字。

**放大鏡（取代主圖上的深圳點）**
```
圓心 (300, 820)，半徑 190
內部為香港—深圳區域的真實比例放大（約 12 倍）
以圓形遮罩裁切（不用矩形），1px 環 `#6FB4D2`
標題：「香港 — 深圳 · 12×」14px，置於圓上方 10px，左對齊圓的左緣
```
- 圓內畫出香港、深圳兩個點與連線，位置**按經緯度實際比例**計算，不得手擺。
- 由主圖香港點向放大鏡畫一條**柔光錐**（上寬 2px、下寬 26px，透明度 0.10），取代虛線。
- 圓形與全片年輪語言一致，比矩形乾淨。

### 3.3 航線：大圓插值 + 調制

**計算**（每條航線獨立）
```
1. 以起訖經緯度做球面大圓插值，取 120 點（slerp）
2. 每點投影為螢幕座標
3. 對投影後路徑施加法向偏移：
   t    = i/119
   A(t) = A0 · sin(π·t)          // 兩端歸零
   off  = A(t) · sin(2π·2.5·t)
   P    = point(t) + normal(t)·off
4. 以折線連接，點距 ≤5px
```
- `A0`：香港→紐約 **9px**；香港→新加坡 **5px**。
- 大圓插值方向取**短弧**，避免繞地球一圈。
- 紐約段應自然越過北太平洋與北美，不得橫切歐亞大陸。**渲染後截圖確認。**

**描邊**（沿用三層，不得用高斯模糊）
| 層 | 寬 | 顏色 | 透明度 |
|---|---|---|---|
| 外 | 18px | `#8DD8F4` | 0.08 |
| 中 | 8px | `#B7E7F8` | 0.18 |
| 內（主線） | 2.4px | `#E8F8FF` | 0.96 |
| 內（副線） | 1.6px | `#E8F8FF` | 0.72 |

**領頭點**：9px 亮點 + 20px 柔光；沿路徑以**浮點**取樣（禁索引跳格）；拖尾 60px 漸隱。
**抵達**：6% 縮放脈衝 + 擴散環（見 PROMPT_12 第 2.3 節，規格不變）。

### 3.4 標籤位置（避免疊字）

| 城市 | 標籤位置 |
|---|---|
| 香港 | 點左下 20px |
| 紐約 | 點左下 20px（不放在右側，避免出界） |
| 新加坡 | 點右下 20px，副標「籌備中」在其下 |
| 深圳 | **只在放大鏡內出現** |

所有標籤距畫面邊緣 ≥40px；標籤不得與航線交叉（由向量方向自動判定）。

### 3.5 背景

沿用 PROMPT_12：陸地 2.8s→6.2s 橫移 40px、經線視差、填充透明度 0.60–0.68 起伏。**顏色改用第 1 節新值。**

## 4. 三語版本

### 4.1 架構

新增 `src/config/locale-v12.ts`：
```ts
type Locale = 'yue' | 'en' | 'zh-CN'
```
所有畫面文案、字幕、VO 路徑由 locale 決定；**畫面結構、時間軸、動效參數完全共用同一份**，不得為不同語言各寫一套 Scene。

### 4.2 繁體 → 簡體

- 僅對文字做簡繁轉換（`s2t` → `t2s`），**不得改寫任何一句**。
- 逐句核對，特別是「嘅」（粵語口語，簡中版須改為書面語「的」，並同步調整整句，見下表）。
- 簡中版不保留粵語口語；粵語版不動。

### 4.3 英文版

- 拉丁字型改用 `public/fonts/Geist.ttf`（已存在），**不用 Noto Sans TC 排英文**。
- 英文行長較中文長，字級需逐行自適應：`fitSize(base, maxWidth)`，不得溢出安全區。
- 大標英文用**句首大寫**，不用全大寫（全大寫在 200px 字級下過於壓迫）。

### 4.5 配音

- 粵語版：沿用現有 VO，完全不動。

## 1. 獎項鏡：提速 + 光的掃過

### 1.1 時間（配音結束後 0.84 秒切走）

旁白實測：`23.62 每一個數字背後` / `25.20–27.96 都有一個家庭，對未來嘅期望` / `28.84 所以，我哋一直向前`

| 項目 | 幀 | 秒 |
|---|---|---|
| 上場 | 705 | 23.50 |
| 照片入場完成 | 729 | 24.30 |
| **切走** | **864** | **28.80** |

- 鏡長 **5.30s（159 幀）**，比原本 7.2s 短 1.9s。
- 省下的 1.9s **全數給地圖鏡**（見第 2 節），總長不變。
- 入場由 1.2s 壓到 **0.8s**：照片錯開由 5 幀改為 **3 幀**，單件時長 0.45s 不變。

### 1.2 讓靜止變成「活著的靜止」：一道掃光 + 微視差

**掃光**
- 0.90–2.50s（18–75 幀）一道柔光由左掃到右。
- 實作為一條寬 700px 的線性漸層遮罩，疊加 `screen` 混合、最高提亮 **+4%**。
- 被掃過的獎座立即提亮，離開後 0.4s 回落；**光帶本身不可見**，只看到明度在移動。
- 不得使用 bloom、光斑、濾鏡模糊。

**微視差**（讓前後排分開，不再像貼在同張紙上）
- 後排（6 件文件）整體右移 **+18px**
- 前排（4 件獎座）整體右移 **+55px**
- 皆為 0.9s → 4.6s 的線性緩移，同方向、不同速度。
- 位移不得影響底邊對齊（僅水平）。

**其餘不動**：底邊對齊、光學等比、無投影無邊框、片尾毛筆字。

## 2. 地圖鏡：加律動、加抵達感、刪掉放大框

鏡頭區間改為 **864–1141 幀（28.80–38.05s，9.25s）**，比原本 7.35s 多 1.9s。

### 2.1 刪掉左下角放大框

**整個移除**：`rect`、框內「香港—深圳 · 局部放大」文字、框內兩個點與連線，以及主圖到框的指示線。

理由：本鏡已有四個地名要讀（香港、深圳、紐約、新加坡），再加框內兩個就是六個，9 秒讀不完。改為在香港、深圳兩點各加一條 40px 引線，把標籤錯開到不同方向（香港標籤往左下、深圳往右上），避免重疊。

### 2.2 線條：調制貝塞爾（把「弧」變成「軌跡」）

- 每條航線仍為單一三次貝塞爾（沿用 PROMPT_09 的控制點公式）。
- 沿曲線以 `getPointAtLength` 取樣 **120 點**，對每點施加法向偏移：

```
t   = i / 119                       // 0→1
A(t) = A0 * sin(π·t)                // 兩端歸零，避免起終點飄移
off  = A(t) * sin(2π * 2.5 * t)     // 2.5 週
P    = point(t) + normal(t) * off
```

- 振幅 `A0`：主線（香港→紐約）**8px**；副線（深圳、新加坡）**5px**。
- 取樣點距 ≤5px，連成平滑折線。
- 三層發光沿用 PROMPT_09 B3 的規格（18px/8% + 8px/18% + 2.2px/92%），**不得改回高斯模糊**。

### 2.3 抵達效果：「按下再回位」（採納使用者想法，但幅度減小）

使用者提出地名放大再縮回。方向正確，但直接放大 20% 會像網頁 hover。改為 **6%**，三層同時發生，總時長 0.62s：

| 元素 | 動作 | 時間 |
|---|---|---|
| 城市名 | 100% → **106%** → 100% | 上去 0.12s `easeOut`，回來 0.5s `easeOutQuint` |
| 城市點 | 5px → 9px → 7px | 同上 |
| 擴散環 | 由點擴至 26px，透明度 0.6→0 | 0.45s |

- 變形原點為該點本身，不得影響周圍文字。
- 動畫期間地名**不得越出安全區**（距畫面邊緣 ≥40px）。
- 若再加元素，只允許一項：地名下方細線由 12px 延展至 40px、0.3s。**四個元素封頂，不再增加。**

### 2.4 背景不能再是死的

- 陸地整體橫移 **40px**（由右往左）於 2.8s→6.2s 內完成；經線同步移動，產生視差。
- 陸地填充透明度在 **0.60–0.68** 之間以 3s 週期緩慢起伏。
- 年輪紋理不動。

### 2.5 節奏配上新時長

| 城市 | 起跑 | 時長 |
|---|---|---|
| 深圳 | 0.4s | 0.45s |
| 紐約 | 0.58s | 1.05s |
| 新加坡 | 0.85s | 0.85s |

新增的 1.9s 全部用在**兩個「呼吸」**上：紐約抵達後靜 0.8s，新加坡抵達後靜 1.2s。不要用新增時間加快節奏。

## 3. 平台鏡：由「一條線五等分」改為同心環

現有問題：上方五個節點（保險·信託·稅務·教育·身份）與下方三行小字（核心保險業務·家族辦公室·財富管理）是兩套邏輯疊在一起，觀眾分不清誰包含誰；且一條橫線五個點是 PPT 裡最平的畫法。

### 3.1 幾何（1920×1080）

```
圓心 (960, 596)

中心    宏泰樹形負形，直徑 120px
內環    半徑 210，三段扇形，每段 120°，間隔 6°
        · 核心保險業務
        · 家族辦公室
        · 財富管理
外環    半徑 400，五個節點，間隔 72°
        · 保險  信託  稅務  教育  身份
        每個節點以短線（60px）連回對應的內環板塊，形成「樹枝」
盈信    掛在「家族辦公室」扇區外緣，直徑 220px 的米白襯底
```

- 內環三段用**描邊不填充**（2px），只在標題處加短弧強調。
- 外環五點為 8px 實心圓 + 30px 標籤。
- 標題「一個平台，連繫未來。」維持現有位置與字級，**不與環相交**。

### 3.2 每一段配一句實據（這才是「簡約中透複雜」）

| 板塊 | 附帶資訊（小字，≤18px，透明度 0.65） |
|---|---|
| 核心保險業務 | 香港 · 澳門 · 美國 · 百慕達 · 新加坡 |
| 家族辦公室 | 盈信家辦 EVERGREEN |
| 財富管理 | 信託 · 遺產 · 稅務規劃 |

- 資料來源：p13「一站式全球資產配置與家族事務平台」。
- 小字放在**扇區內側**，不得壓在弧線上。

### 3.3 動畫：生長，不是連線

```
0.00s  中心樹形亮起
0.30s  內環三段沿圓周依次畫出（各 0.25s，錯開 0.18s）
1.20s  外環五項由內環「長出」短線 + 標籤（各 0.30s，錯開 0.12s）
2.40s  盈信 logo 在家族辦公室末端淡入
2.80s  完全靜止（直到鏡尾）
```

- 環的繪製用 `stroke-dasharray` 逐段推進，不用旋轉。
- **不得**整圈同時出現、不得旋轉、不得加光暈。

### 3.4 明確不做

- **不放照片**。此鏡是全片最抽象的一鏡，放照片會讓「平台」概念變模糊；且上一鏡剛放九張辦公室實景，連續實景會疲勞。
- 不用 PPT 的彩虹色節點圖（p14）、不用彩色圓餅（p14 左側）。
- 不新增 PDF 以外的板塊或服務項目。

> PROMPT_13（三語、提亮藍）與 PROMPT_14（人物鏡、加長）照做；本檔**取代** PROMPT_12 第 1、2、3 節及 PROMPT_13 第 2、3 節中與下列五鏡衝突的版式規格。

## 0. 使用者回饋（2026-10-26 截圖）

1. 品牌牆（100億+ / 15億+）：灰色方塊格子像 PPT，且中間有一條「銀行」分隔線 → 刪線，重做展示方式。
2. 獎項鏡：文件與獎座前後疊在一起，雜亂 → 重做。
3. 地圖鏡：航線仍然扭曲 → 改為一條乾淨曲線；城市點要準確。
4. 平台鏡：字太小、整體擠迫。
5. 根深鏡：標題字太小，與右邊大樹不對稱。

## 1. 品牌牆：去格子，改為「單色雙軌流動」

### 1.1 問題根源
25 個彩色 logo 各帶灰底方塊，顏色、字重、留白全不統一，畫面重心被方塊搶走，數字反而變配角。

### 1.2 新版式（1920×1080）
```
左上   小標「集團總保費」/「集團總佣金」  28px  字距 4   x=130 y=300
左     大數字 100億+ / 15億+               280px          x=130 y=340–620
       「港元」                            36px           數字下方 24px
下方   兩條 logo 軌道，滿版寬（0–1920），左右各以 160px 漸隱遮罩收邊
       軌道 A  y=760  中心線   向左流動
       軌道 B  y=880  中心線   向右流動
       速度 24px/s（極慢，像呼吸，不像跑馬燈）
```
- **刪除所有方塊底、邊框、「銀行」分隔線與文字。**
- Logo 一律轉為**單色米白 `#F4EEE2`、透明度 0.78**：以原圖做 alpha 剪影（白底去除 → 亮度轉 alpha），存 `public/logos/mono/`。邊緣有雜點者手動清理；完全無法乾淨剪影者回報，不得糊上。
- **光學等高**：每個 logo 依視覺重量統一到「等面積」——以包圍盒面積 ≈ 6000px² 為目標，高度上限 56px、寬度上限 220px；logo 間距 72px。
- 軌道 A：保險公司前 13 個；軌道 B：其餘保險公司 + 中國民生銀行、上海商業銀行（銀行併入同一流中，不再區分）。
- 兩個數字鏡**軌道連續不重置**：15億+ 鏡接續 100億+ 鏡的流動位置，只換左側數字，營造同一場景。

### 1.3 動畫
| 時間 | 動作 |
|---|---|
| 0.00s | 小標淡入上浮 12px，300ms |
| 0.10s | 數字由 0 計數至終值，600ms easeOut；逐位等寬（tabular-nums），不得抖動 |
| 0.30s | 兩條軌道由透明 0→0.78 淡入，500ms，同時開始流動 |
| 數字切換 | 舊數字上移 24px 淡出 250ms，新數字自下 24px 升入 400ms；軌道不停 |

## 2. 獎項鏡：「一列展台 + 對聯左右對稱」

### 2.1 問題根源
6 件平面文件在後、4 座獎座在前，彼此遮擋；對聯縮成小框擺在角落，主次不清。

### 2.2 新版式
```
標題   「每一份信任，都有分量。」  維持現有位置與字級
副標   「業界肯定，見證專業積累」  28px（原 22px 過小）
左右   兩幅對聯作書檔：永明在左 x=130，友邦在右（右緣 x=1790）
       高 600，y 300–900，完整呈現、不裁、不鏡像
       下方 12px 標籤：「永明金融 SUN LIFE」「友邦 AIA」 16px 字距 2 透明度 .72
中央   4 座獎座一字排開於 x 520–1400，底邊統一 y=860
       光學等高（視覺高度 480–520px），間距相等
       順序：Blue Whale Award → Best of the Champions 2022 → 2023 → 2024
地面   底邊下方畫一道倒影：獎座垂直翻轉，透明度 0.12，120px 線性漸隱
       + 一條 1px 地平線 #6FB4D2 透明度 .35，x 480–1440
```
- **刪除 MVP 證書、黑色獎牌、粉色證書等 4 件平面文件**（不再進此鏡）。刪減寫入 QA。
- 獎座下方各一行小字 16px 透明度 .65：`中國太平洋保險 · Blue Whale Award`、`中銀人壽 · 2022` 等，**逐字依獎座實物文字**，看不清者不寫。
- 去背：獎座必須是乾淨 alpha（現有 4 張 native 圖若帶背景，先去背再用；邊緣羽化 ≤1px）。

### 2.3 動畫（鏡長沿用 5.30s）
| 時間 | 動作 |
|---|---|
| 0.00s | 對聯左右同時由外側 32px 滑入淡入，500ms |
| 0.20s | 4 座獎座由下 24px 升起，錯開 3 幀，每座 500ms；倒影同步 |
| 0.90–2.50s | PROMPT_12 掃光（+4% 明度，光帶不可見）由左至右掃過 4 座 |
| 全程 | 整體鏡頭推近 1.00→1.025，線性 |

## 3. 地圖鏡：一條乾淨的弧 + 精準定位點

### 3.1 問題根源
PROMPT_13 的大圓插值在等距圓柱投影上，香港→紐約會貼近北極再落下，畫出「先直上、橫拉、再直落」的訂書釘形；再加法向正弦調制，更顯扭曲。**大圓在這種投影上本來就不好看，放棄大圓與調制。**

### 3.2 航線：單一二次貝塞爾
```
P0 = 起點螢幕座標，P2 = 終點螢幕座標
d  = |P2 − P0|
M  = (P0 + P2) / 2
N  = 垂直 P0P2、朝畫面上方的單位法向量
P1 = M + N · d · 0.28          // 弧高 = 距離的 28%（紐約段約 210px，新加坡段約 30px 太小 → 最小 60px）
```
- 每條航線一條 `<path d="M P0 Q P1 P2">`，**直接用 SVG 曲線，不取樣成折線、不加任何偏移**。
- 描邊兩層：主線 2.4px `#E8F8FF` .96 + 外光 8px `#B7E7F8` .16（用描邊疊加，不用模糊濾鏡）。
- 繪製：`stroke-dashoffset` 由長度推至 0，800ms；領頭點沿 `getPointAtLength` 浮點取樣。
- 刪除 PROMPT_13 第 3.3 節的 slerp、120 點、`A0` 調制、18px 外層。

### 3.3 城市點：真實經緯度 + 定位標
| 城市 | 經緯度（WGS84） |
|---|---|
| 香港（尖沙咀） | 22.2988°N, 114.1722°E |
| 深圳（南山） | 22.5333°N, 113.9300°E |
| 紐約（Flushing） | 40.7580°N, 73.8303°W → 經度換算 286.17 |
| 新加坡 | 1.2830°N, 103.8510°E |

- 一律由經緯度經同一投影函數計算，**刪除 `world-v12.json` 中手寫的城市座標**；先核對該投影與陸地底圖是否同源（用 3 個已知海岸點驗證，誤差 ≤2px，否則先修投影）。
- 定位標設計（取代單純白點）：
```
實心點   6px  #F4EEE2
細環     16px 直徑，1px，#F4EEE2 .6
十字刻度 環外四方向各 6px 短線，1px，.5     // 像瞄準鏡，傳達「精準」
```
- 標籤：城市名 32px 600 + 下方英文 14px 字距 3 透明度 .65（HONG KONG / NEW YORK / SINGAPORE），位置照 PROMPT_13 §3.4；標籤與弧線用包圍盒檢查不相交。
- 新加坡加副標「籌備中」，點改為**虛線細環**（尚未開業的視覺區分）。

### 3.4 放大鏡
- 保留圓形放大鏡（截圖中的設計可用），但倍率標示必須是**實際計算值**（截圖寫 48×，PROMPT_13 寫 12×，以實算為準）。
- 圓內香港、深圳同樣用定位標、同一經緯度換算，兩點距離 ≥60px。
- 主圖香港點到放大鏡用柔光錐（PROMPT_13 §3.2）；放大鏡內圖說 14px 改為 18px。

## 4. 平台鏡：放大、放鬆

### 4.1 問題根源
圓環半徑僅約 160px，內部塞了三個板塊名 + 兩行小字 + logo，字只有 14–18px；外環五點擠在圓周近處，盈信 logo 壓住「身份」與「教育」之間。

### 4.2 新幾何
```
標題   「一個平台，連繫未來。」 縮至 96px，左上 x=130 y=150，與下方圖不爭主角
圖形中心 (1060, 620)，向右偏移讓出左側留白
中心   宏泰樹形 140px
內環   半徑 230，三段扇區描邊 2px
       扇區名 36px 600（原約 20px）· 附註 20px 透明度 .7（原約 13px）
       字放在扇區外側弧邊外 28px，不塞在圈內
外環   半徑 400，五節點 10px 實心圓 + 標籤 40px（原約 26px）
       節點到內環連線 1px .5
盈信   移出圓環，放在左下獨立位置 x 130–430 y 720–900：
       米白圓 200px + 下方一行 22px「家族辦公室 · 盈信家辦 EVERGREEN」
       以一條 1px 細弧連到「家族辦公室」扇區
```
- 所有文字最小 20px；任意兩個文字包圍盒間距 ≥24px（腳本量測）。
- 動畫沿用 PROMPT_12 §3.3（生長，不旋轉）。

## 5. 根深鏡：左右對稱

### 5.1 問題根源
標題約 56px，佔畫面左側不到 1/5；右側大樹約 600px 高，兩邊重量嚴重失衡。

### 5.2 新版式
```
畫面分兩欄，中線 x=960
左欄   標題兩行，字級 128px 700，行高 1.15，色 #0B2E45
       「根扎得深，」「長得更高。」
       文字塊垂直置中於樹的包圍盒中心（y≈450），左緣 x=180
       下方 40px 一條 80px × 3px 朱砂短線
       換句時（「步伐夠穩，走得更遠。」）同位置替換：舊句上移 24px 淡出 250ms，新句升入 400ms
右欄   大樹縮至高 560，水平置中於右欄（中心 x=1400）
       樹底橫條與左欄文字塊底邊在同一水平線（目視基線對齊）
```
- 左欄文字塊與右欄樹的**視覺面積比約 1 : 1.2**，量測寫入 QA。
- 英文版標題 96px，以 `fitSize` 限寬 700px。

### 1.3 兩個必須知道的坑

**坑一：張志凌的照片在 PDF 裡重複存了兩次。**

### 1.4 不要用截圖，用內嵌原圖

使用者說「截圖」，但 PDF 內嵌的原圖比螢幕截圖清晰得多（截圖會二次壓縮並帶上頁面背景）。請直接抽原圖：

```bash
pdfimages -f 19 -l 19 -png 宏泰国际公司介紹_SC_2026年10月14日.pdf <輸出目錄>/p19
```

抽完後 P19 的內容物大致是：2 張 2880×1620 背景、5 張人像 RGB、5 張對應灰階 smask、以及重複的一組。**人像必須與 smask 合成 alpha**，否則會是黑底。

合成方式（smask 是同尺寸灰階圖，當 alpha 用）：

```bash
python3 -I -c "
from PIL import Image
im = Image.open('p19-013.png').convert('RGB')
m  = Image.open('p19-014.png').convert('L')
if m.size != im.size: m = m.resize(im.size, Image.LANCZOS)
im.putalpha(m); im.save('portrait-01-david-wang.png')
"
```

## 2. 設計方向：紀實編輯體，不是史詩體

### 2.1 為什麼要換氣質

香港版走「克制＋慢推＋年輪隱喻＋12 秒 Logo 生長」，在中文語境是高級感。但美國招募市場有三個現實：

- 前 12 秒沒有資訊會被判定成「外國金融機構的宣傳片」直接划走。
- 交響樂＋航拍＋男聲旁白那套符號，本地觀眾已完全免疫，容易被讀成 infomercial。
- 涉及跨境時，預設心態是防禦性的。

**結論：美國版要從「抒情」改成「紀實」——不試圖說服，只是讓人看見。**

### 2.2 人物鏡的定位

這一鏡是全片可信度最高、成本最低的一段。它要傳達的資訊只有一句：

> **這些人是真的，而且他們本來就是從美國保險業裡出來的。**

所以**不要煽情、不要慢動作、不要光暈、不要人物特寫推鏡**。做成雜誌內頁的人物欄，而不是頒獎典禮的英雄榜。

### 2.3 名字比頭銜有用

美國候選人認得的是公司名，不是中文職級。卡片文字建議：

```
Lily Ku
New York Life · MassMutual
```

前雇主 > 頭銜。這是整個設計裡最反直覺、但最有效的一點。

## 3. 版面規格（1080p / 30fps）

> 專案基準：1920×1080，30fps（與 v12 全片 2103 幀 / 70.1s 同一時間基準）。
> 色彩與字體一律沿用 `video/src/theme.ts`，不得新增色票。

### 3.1 不要摳像 —— 用「統一影調」吃掉背景差異

六張底色不同（藍灰攝影棚 vs 白底），硬摳邊會露出鋸齒，而且 282px 的圖摳完只剩下巴一堆毛邊。

**改法：保留原背景，只做裁切＋統一調色。**

- 全部裁成 **4:5 直式**（中心裁切，以臉部為中心對齊，容許上下微調）。
- 統一調色：降飽和 → 疊一層 ink 色調 → 加輕微暖色偏移，讓六張讀起來像同一組拍的。
- 這一招在低解析度下反而最穩：看不出像素，因為觀眾看的是「一組人」而不是「每張臉」。

### 3.2 卡片尺寸：224×280，且**不得放大超過 1.0 倍**

224×280 是 8px 網格（28×8 / 35×8），同時滿足六張原圖**全部不需要上採樣**：

| 姓名 | 裁 4:5 後 | 放到 224×280 的倍率 |
|---|---|---|
| 王浩 | 306×382 | 0.733 |
| 谷林丽 | 340×425 | 0.659 |
| 张志凌 | 291×364 | 0.769 |
| 罗英姿 | 318×398 | 0.703 |
| 胡忠瑶 | 226×282 | **0.993** |
| 王娟 | 457×571 | 0.490 |

**胡忠瑶那張是臨界值（0.993）。這個尺寸不能再小，整組也不能再放大。**
若日後要出 4K，必須重新取得素材，不能靠插值。

### 3.3 兩個版面方案

**方案 A（推薦）：六格編排**

- 3 欄 × 2 列，卡片 224×280。
- 水平間距 40，垂直間距 56 → 整體 752×616，畫面居中。
- **交錯 16px 垂直位移**（單數列下移），讓它讀起來像雜誌跨頁，不像 PPT 表格。
- 王浩那張**不放大**（放大就破格），改為在姓名行上方加一行 12px 的 `US GENERAL MANAGER` 小標——用文字建立層級，不用尺寸。
- 姓名：Source Serif 4 / 24px；前雇主：Geist / 14px / muted，`letter-spacing: 0.06em`。

**方案 B（備選，要動感時用）：單排漂移帶**

- 六張一字排開，總寬 6×224 + 5×40 = 1544。
- 由右向左緩移 120px，時長 = 整鏡長度 × 0.7，之後靜止。
- 適合 6 秒以上的鏡頭；4 秒以下用方案 A。

**推薦 A。** 六個人在 5–6 秒裡，觀眾讀的是整體印象，不是逐張看；移動的橫排反而分散注意力。

### 3.4 動效

| 項目 | 規格 |
|---|---|
| 入場 | 每張卡片 `opacity 0→1` + `translateY 12px→0`，時長 0.35s |
| 錯開 | 每張間隔 **3 幀**（0.1s），六張共 0.5s 鋪滿 |
| easing | `theme.ease`（cubic-bezier 0.16, 1, 0.3, 1） |
| 姓名文字 | 比卡片晚 6 幀淡入，`opacity 0→0.85` |
| 全鏡收尾 | 卡片**不做**任何縮放或推鏡，直接淡出 0.3s |

**禁止**：Ken Burns 推鏡、人臉 zoom、3D 翻轉、卡片投影、邊框、圓角以外的裝飾。

### 3.5 背景與留白

- 底色 `paper`：`oklch(97% 0.01 80)`
- 不做任何背景圖、不做漸層、不做紋理。
- 上方留出約 120px 給一行標題，下方留 96px 安全區。

### 3.6 標題（建議文案，需公司確認）

```
Our US partners came from the companies you already know.
```

或更短：

```
Built by people from the industry you're already in.
```

標題用 Source Serif 4，43px，`ink` 色。**不要用中文，不要雙語並列**——出現中文會立刻把片子歸類成「給華人看的」，這是美國版最需要避免的誤判。

## 4. 英文配音與音樂（使用者已明確要求）

> 使用者原話：「音乐和配音风格也是全英文的，也都是利用 minimax voice 配音进行生成」
>
> **兩件事都要全英文**：配音是英文，音樂風格也走英文（美式）語感。音樂不用人聲唱歌，所以「全英文」在這裡指**聲音整體朝向美國市場**，不是指歌詞。

### 4.1 沿用香港版已有的 MiniMax 管線

香港版 v4 已經跑通一整套流程，美國版**不要另起一套**，直接複製參數結構：

| 項目 | 香港版 v4 現狀 | 美國版要改成 |
|---|---|---|
| 供應商 | MiniMax 網頁版（使用者授權的 Chrome 分頁） | 相同 |
| 模型 | `speech-2.8-hd` | **相同** |
| 音色 | `Gentle Lady - Clear,Melodic,Gentle` | **需重新挑選**（見 4.2） |
| 語言 | Cantonese | **English (US)** |
| speed | 0.95 | **0.98–1.02**（見 4.3） |
| pitch | 0 | 0 |
| volume | 1 | 1 |
| 對齊 | 本地 Whisper tiny，參考文本強制對齊 | 相同，但 `language='en'` |
| 產出 | `public/vo/hk-v4/VO-0N.wav` | `public/vo/us-v1/VO-0N.wav` |
| 來源記錄 | `VOICE_PROVENANCE.json` | 必須同樣產出一份 |

參考實作：`video/scripts/prepare-minimax-v4.py`。**這支腳本可直接複製改名為 `prepare-minimax-us.py`**，只需改三處：

```python
profile = json.loads((ROOT/'src/config/performance-us-v1.json').read_text())   # 新配置
out = ROOT/'public/vo/us-v1'                                                   # 新輸出目錄
tokenizer = get_tokenizer(..., language='en', task='transcribe')               # 改英文
```

其餘的對齊邏輯、`subtitleChunks` 切分、AAC 封裝、時間軸回寫**全部不動**。這是本專案已驗證過的路徑，不要重寫。

### 4.2 音色怎麼選（這是美國版最容易做錯的一步）

**不要用香港版那個「Gentle Lady」。** 那個音色的成功之處在於「溫和、有感情、少機械感」，在粵語語境裡是加分；但同一個氣質搬到美式英語裡，很容易變成「客服語音」或「電商廣告」，這是美國觀眾最反感的兩種聲音。

美國招募片的配音基準是 **NPR 播音員 / 紀錄片旁白**，特徵是：

- **中低音、略微沙啞、氣息靠前**（不是明亮甜美的高音）
- **語速正常偏慢，但不拖**，句尾下沉而非上揚
- **幾乎沒有情緒起伏**——不是冷淡，是「我沒必要討好你」
- 有輕微的**美式口音錨點**（r 音、t 濁化），但不要刻意地區腔（南方腔、紐約腔都會分散注意力）

在 MiniMax 的音色列表裡按這個方向試聽，**至少挑 3 個候選，各錄同一句做 A/B**：

> "I came from New York Life. Twenty years in this business. Here's what we actually do for new advisors."

試聽時只問一個問題：**這個人像不像一個你會願意坐下來聽他講十分鐘的人？** 像，就對；不像，換。

候選清單與最終選擇請寫進 `performance-us-v1.json` 的 `voiceDisplayName`，並把試聽檔一併存檔，理由同香港版——日後重錄要能復現。

### 4.3 語速與斷句

- **speed 0.98–1.02**。香港版用 0.95 是因為粵語書面語讀起來需要留呼吸感；英文 narrated 語速本來就快，再放慢會顯得做作、像在對外國人說話。
- **不要為了對齊畫面而加速播放**。香港版已明確禁止 `playbackRate ≠ 1`，美國版沿用：寧可重寫句子或調整鏡長，也不變速。
- **字幕切分**（`subtitleChunks`）按**語意單位**切，不按字數切。美國版若不上字幕，這欄仍要填——它同時是對齊腳本的計時依據。
- 句尾停頓用 MiniMax 的 `<#秒數#>`；英文建議 0.3–0.6s，不要超過 0.8s（英文停太久會像卡住）。

### 4.4 音樂：不是「英文歌」，是「美國耳朵聽的配樂」

香港版 v11/v12 用的是 `bgm-A.mp3`（史詩弦樂向，經 A-edit 剪輯成 70.1s，見 `public/music/v11/ASSET_ROLES.json` 與 `src/config/beats-v11.json`）。

**美國版必須換掉這首。** 交響樂 + 大鼓 + 航拍在美國招募語境裡是 infomercial 的標準配置，觀眾已完全免疫。這不是品味問題，是市場效率問題。

建議方向（按優先級）：

1. **極簡鋼琴 / 單樂器**——一個音符一個音符地走，允許留白。風險最低。
2. **低頻脈衝電子（minimal pulse）**——有節奏但不煽情，適合有人物出鏡的段落。
3. **近乎無配樂**——只留環境聲與人聲。如果配音夠好，這是最有說服力的選擇。

**技術要求**：

- 不要用有明顯旋律記憶點的曲子（觀眾會分心去想「這首是什麼」）。
- **不要在人聲段落下重音**。BGM 峰值應比旁白低 **至少 12 dB**；香港版現行混音可作參考（`review-mix-headroom.wav` 已預留 headroom）。
- 剪輯沿用 `beats-v11.json` 的 span / crossfade 結構（`crossfade_s: 0.4`），只換素材，不改結構。
- 素材需**授權可商用**，並在 `ASSET_ROLES.json` 裡登記來源。香港版那首若無明確商用授權，美國版不要沿用。

### 4.5 人聲與音樂的取捨（美國版的關鍵決定）

香港版是「音樂主導」，旁白疊在上面。**美國版建議反過來：人聲主導，音樂托底。**

理由：這段片的任務是建立信任，而信任只從人聲來。如果觀眾記住的是配樂而不是說話的人，這支片就失敗了。

具體做法：人物鏡出現時，BGM 自動 duck 到 **-18 dB**，人聲結束後 0.5s 內回到原音量。這一條寫進混音腳本，不要靠手動調。

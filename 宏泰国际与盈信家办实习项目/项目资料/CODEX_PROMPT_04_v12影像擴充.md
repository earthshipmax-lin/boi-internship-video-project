## 0. 使用者回饋與本輪目標

v11 畫面結構已獲認可，但**實景圖片不夠**。目前全片 12 鏡只有 2 處實拍（`stills/v11/awards.jpg`、`hong-kong-office.jpg`），其餘都是文字與圖形。
使用者要求：**要放入更多 PPT 實景圖，而且基本都要放進去，但不能突兀；圖片的出入場順序非常重要。**

本輪不解釋、不重寫文案、不改配音與音樂，只做一件事：**建立一套統一的影像語法，把 PDF 裡可用的圖系統性地放進 v11 已有的敘事骨架裡。**

## 1. 核心原則：一套語法，不是一張一做法

現在 awards 與 office 兩張圖各自獨立，沒有共同規則，所以每加一張就多一種視覺習慣，必亂。
本輪所有圖片**必須共用下列同一套規則**，圖片數量增加反而顯得系統化。這就是「簡約中透露複雜」。

### 1.1 入場（全片統一，不得自創變體）

```
遮罩：clip-path inset(0 100% 0 0) → inset(0 0 0 0)
時長：0.45s（13–14 幀）
曲線：easeOutQuart（1-(1-x)^4），與 v11 現有 ease 一致
同時：scale 1.06 → 1.00，transform-origin 依圖片在畫面中的位置，永遠朝畫面中心
```

### 1.2 出場

- 與入場**同方向繼續前進**，被畫面邊界裁掉（遮罩另一側 open），**不做淡出**
- 禁止：兩側飛入、回彈／elastic、旋轉、隨機抖動、逐張不同緩動

### 1.3 色調統一（關鍵，解決「像貼白紙」）

PPT 截圖多為白底，直接放到深藍版面上會刺眼。每張圖統一處理：

```
底層：8% #0B2E45 疊加（multiply 或 rgba 疊層）
對比：+6% 微調
飽和：-8%
```

實作可用 Remotion 的 CSS `filter: contrast(1.06) saturate(.92)` 加一層深藍半透明覆蓋，**不做黑白、不做雙色調、不加光暈與邊框**。圖片邊界只用遮罩裁切，不要加描邊或陰影。

### 1.4 排序規則（四條，依優先級，寫進 `src/config/photos-v12.ts` 註解）

1. **一鏡一方向**：同一鏡內所有圖只能同向運動（全右移或全上移），全片不混用方向。
2. **時間序**：先舊後新（1997 → 現在）。
3. **空間序**：由近及遠（香港 → 深圳 → 紐約 → 新加坡籌備中）。
4. **權威序**：由小到大（單個獎座 → 獎盃牆 → 機構 Logo 牆）。

## 3. 不放的素材（明確排除，不要自行加回）

- **團隊照片 p15–p18（劉天生、李冠成、王浩等）**：含真人肖像與姓名，對外形象片需要本人書面授權。以辦公室實景替代。

- **任何頁面殘留的 PPT 標題條、頁碼、頁腳與英文小字**：裁切時必須裁掉，畫面只保留照片本身。

- 新鏡入場點對齊 `onsets_s` 最近的實測拍點（容差 ≤0.18s，沿用 v11 的 `snap()` 邏輯）。

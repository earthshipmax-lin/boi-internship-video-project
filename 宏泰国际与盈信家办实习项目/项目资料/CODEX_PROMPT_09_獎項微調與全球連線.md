## B. 全球連線：整段重做

### B0. 現有實作的四個具體缺陷（已讀 `GeographicNetworkV12.tsx`）

1. **線是折線**：`points()` 用 `M… L… L…` 串接，弧線由大量短直線構成，放大即見鋸齒感。這是「線條不優美」的直接原因。
2. **光暈靠高斯模糊**：`strokeWidth 6 + feGaussianBlur stdDeviation 3`。深底上發灰、邊緣髒，且成本高。
3. **領頭點跳格**：`coords[idx]` 用整數索引，小球逐段跳動，非平滑移動。
4. **主次不分**：三條航線粗細、透明度幾乎相同；香港—紐約明明是主線。

另有：左下角放大圖為直角矩形 + 直線，與全片圓潤的年輪語言不一致；放大圖與主圖之間以虛線指示，關聯弱。

### B1. 設計概念

**不要畫「城市之間的連線」，要畫「一條從香港出發的航跡」。** 全片只有一個出發點、一個運動主體。

### B2. 曲線

- 每條航線為**單一三次貝塞爾**（SVG `C`），不得使用多段 `L` 或多段 `C` 拼接。
- 控制點計算：由起點與終點求中垂線，控制點抬升量 = 弦長 × 0.18，方向朝畫面外側（上方）。
  ```
  P0 = 起點, P3 = 終點
  mid = (P0+P3)/2
  n   = 垂直於 P3-P0 的單位向量，取 y 分量為負的一側
  k   = |P3-P0| * 0.18
  P1 = P0 + (P3-P0)*0.28 + n*k
  P2 = P0 + (P3-P0)*0.72 + n*k
  ```
- 路徑點以 `path.getTotalLength()` / `getPointAtLength()` 取樣，**不使用預先寫死的座標陣列**。

### B3. 發光（取代高斯模糊）

三層同路徑疊加，邊緣乾淨、顏色為純藍白，不得發灰：

| 層 | 寬度 | 顏色 | 透明度 |
|---|---|---|---|
| 外 | 18px | `#8DD8F4` | 0.08 |
| 中 | 8px | `#B7E7F8` | 0.18 |
| 內 | 2.2px | `#E8F8FF` | 0.92 |

主線（香港→紐約）內層 2.4px / 0.96；副線（深圳、新加坡）內層 1.6px / 0.72，整體透明度再乘 0.8。
**移除 `feGaussianBlur` 濾鏡。**

### B4. 繪製與領頭點

- 進度用**浮點**計算，沿路徑取樣，禁止索引跳格。
- 領頭點：直徑 9px 的亮點（`#F4EEE2`），外加一層 20px、透明度 0.25 的柔光圓。
- **拖尾**：自領頭點往回 60px 的漸隱段，透明度由 1 線性降至 0。實作方式為對同一條路徑套用第二個 `stroke-dasharray` 局部段，或逐幀取 12 個點畫折線（若用折線，點距須 ≤5px，肉眼不可辨）。
- 到達時領頭點**不收縮消失**，改為擴散成一圈 2px 描邊、半徑 8→26、透明度 0.6→0 的環，時長 0.4s。

### B5. 節奏

- 曲線繪製：`cubic-bezier(0.4, 0, 0.2, 1)`，先慢中快，末段減速。
- 紐約 0.95s、深圳 0.45s、新加坡 0.80s。
- 三條**錯開 0.18s** 起跑，順序：深圳 → 紐約 → 新加坡。
- 城市標籤在領頭點到達後 **0.12s** 淡入，不要同時。

### B6. 城市點與標籤

- 主點：5px 實心 `#F4EEE2`，外環 14px / 1px / 0.5，到達時環由 0.6 擴至 14。
- 標籤：33px / 700，距點 20px，永遠放在**遠離線條的一側**（由向量方向自動判定，不要寫死偏移）。
- 新加坡維持「籌備中」21px 副標。**不得把新加坡畫成已設辦公室**。

### B7. 左下角放大圖

- 外框四角圓弧 **6px**，1px `#416F84`，底色 `#0B2E45` / 0.90。
- 框內香港—深圳連線改用貝塞爾（同一套控制點公式），不用直線。
- 主圖與放大框的關聯：**取消虛線指示**，改為從主圖香港點向放大框上緣畫一條柔光帶（寬 8px、`#8DD8F4`、透明度 0.10→0.02 漸變）。
- 框內文字保持「香港—深圳 · 局部放大」，18px，字距 2。

### B8. 明確不做

- 不加飛行軌跡以外的裝飾（無飛機、無光斑、無粒子）。
- 不做地圖 3D 傾斜、不做鏡頭旋轉。
- 不用高斯模糊、不用混合模式做發光。
- 不為求華麗而增加城市或路線，資料只有四地。

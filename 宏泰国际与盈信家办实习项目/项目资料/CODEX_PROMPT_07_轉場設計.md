# CODEX_PROMPT_07：v12 轉場設計 — 年輪光圈擴散

> 由 Claude 撰寫，交 Codex 執行。共用工作區：先讀 `CLAUDE_HANDOFF.md`、`video/README.md`、`CODEX_PROMPT_05_v12第二階段.md`、`CODEX_PROMPT_06_獎項鏡重做.md`。
> 本檔取代 PROMPT_05 第 2 節（深藍↔米白轉場）。該節原本要求「不同底色一律硬切」，那是為了修掉灰層，但硬切造成新的問題：突兀。本檔改成統一的遮罩轉場。
> 新 Composition：`BOI-HK-Epic-v12-Stage4`。既有成片不得覆寫。

## 0. 問題

使用者回饋：深藍與米白背景互換時「很突兀，沒有過渡動畫」。

**根因有兩個，第二個比第一個重要：**

1. 硬切，沒有任何過渡。
2. **相鄰兩鏡構圖完全相同**（同一行大字、同一位置牌照編號、同一角落 Logo），只差整幅顏色反相。眼睛讀到的是「閃了一下」，不是「進入新段落」。

所以修法不能只是「加個淡入」。必須：
- 用**遮罩覆蓋**而不是混色（混色必出灰）；
- 讓轉場有**明確的運動主體**；
- 轉場期間**只允許一個元素在動**。

## 1. 主方案：年輪光圈擴散（Ring Iris）

新場景的底色以同心圓從年輪圓心向外擴張，鋪滿畫面，舊場景被推開。方向無關，藍→白與白→藍共用同一套動作。

### 幾何

```
圓心： (960, 820)  — 沿用全片年輪圓心，不要另設
半徑： 0 → 1270  （從該點到左上角距離約 1263，留 7px 餘量）
邊緣羽化：60px 徑向漸變（硬 clip-path 會鋸齒，必須用 SVG mask 或 radial-gradient 遮罩）
圓周邊緣光：新底色提亮 12%，寬 2px，隨半徑擴張淡出（透明度 0.6 → 0）
```

### 時序（以轉場起始為 0）

| 時間 | 動作 |
|---|---|
| 0.00–0.60s | 光圈由 0 擴至 1270，曲線 `cubic-bezier(0.65,0,0.35,1)` |
| 0.00–0.60s | 舊場景整體 `scale 1.00 → 1.03`（被撐開、退後），透明度不變 |
| 0.60–0.72s | **完全靜止的空白期**（12 幀）。這一拍是關鍵，不要省 |
| 0.72s 起 | 新場景的文字與圖形按各自原有的入場動效開始 |

**鐵律：光圈擴散期間，新場景的文字、圖片、圖表一律不可見。** 文字必須等光圈鋪滿、空 12 幀之後才開始入場。現在的 bug 就是新文字飄在舊底色上（見使用者提供的截圖：米白底上出現深藍的「信任，扎根時間」）。

### 各類鏡頭的特別處理

- **含實景照片的鏡頭**（office）：光圈揭開時，照片必須**已在最終位置、最終尺寸**，不做縮放、不做位移，只被遮罩揭開。否則會像 PowerPoint 的圓形切換動畫。
- **片尾**：最後一個轉場不用光圈，改用現有的 0.4s 明度淡出，讓片子安靜收束。
- **片頭**：第一個場景不套轉場，從黑場淡入即可。

### 音效

若音樂本身在該拍點有轉折或鼓點，不要另加音效。若完全沒有，可在光圈啟動時加一聲極輕的低頻 swell（-28dB 以下，0.7s）。**不可加 whoosh、不可加 riser**。

## 2. 連帶要修：構圖重複

即使加了轉場，「同一行字、同一位置、只差顏色」仍然太像。對構圖相同的相鄰鏡頭，做下列至少一項：
- 大字位置錯開 **≥60px**（水平或垂直）；
- 牌照編號由左下改到右下，或改為豎排；
- 其中一鏡大字改為左對齊、另一鏡居中。

這一項只調整位置，**不改任何文案**。

## 3. 明確不做

- 交叉淡入（`opacity` 混合）——灰層的來源，全片禁用於不同底色之間。
- 白屏閃、黑場，「故障」或「故障感」效果。
- 縮放式轉場（zoom blur）、旋轉、畫面抖動。
- 一次轉場裡同時出現兩種運動（例如光圈擴散時文字同時淡入）。
- 把年輪線本身也做擴散——只有**遮罩**在擴散，背景的年輪紋理保持不動，否則會很亂。

## 4. 驗收

- 抽取每一個場景接縫的連續幀（0.05s 間隔，前後各 0.6s）：`qa/v12/stage4/transitions/`。
- 逐個接縫確認：光圈期間無任何新場景文字可見；光圈邊緣無鋸齒；無灰階混色出現。
- 量測 0.60–0.72s 是否確實存在靜止期（該 12 幀應完全相同）。
- 構圖重複的相鄰鏡頭，位置偏移量 ≥60px 並記錄。

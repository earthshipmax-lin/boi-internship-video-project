> 只改**普通話版片尾三句**的聲音（及隨之微調的最後兩條字幕）。其餘畫面、聲音、粵語／英文版一律不動。不覆寫 V16。

## 0. 使用者回饋（2026-10-27）

V16 普通話片尾語氣「非常糟糕」。要的是**有韻味的雄偉感、抑揚頓挫**。

## 1. V16 為何不對（診斷，不得重蹈）

| V16 做法 | 問題 |
|---|---|
| 四段加 **Happy** 情緒 | Happy 是「開心、上揚、輕快」，與「雄渾、沉穩」相反，聽起來像促銷口播 |
| pitch +1 | 整體音高上提，失去低沉厚度 |
| 整句一次生成 | 模型把四字詞讀成平均節奏，沒有頓挫 |
| 後期 WSOLA 拉長「山／泰／際」 | 人工拖音發虛、發假，不是氣息撐出來的長音 |
| 三層 +2dB 遞增 | 只是變大聲，不是變有力 |

**原則：雄偉感來自「低、慢、停、收」，不是來自高、快、大聲。**

## 2. 目標讀法（逐字聲調與節奏）

以中國紀錄片／央視宣傳片收尾的朗誦腔為參照：胸腔共鳴、字頭有力、字尾收住、句間留白。

```
大 展 —— 宏 圖，        （停 0.6s）
4  3      2  2
「大」重起，「展」稍拖蓄勢，「宏圖」上揚展開，「圖」不拖、穩穩落住。

穩 如 泰 山。           （停 0.9s，全片最長的留白）
3  2  4  1
「穩」低沉起，「泰」重壓下去，「山」平聲長音（自然延長約 0.6–0.8s），收在低位，不上揚。

宏 泰 —— 國 際。        （結束）
2  4      2  4
「宏泰」一口氣，「泰」重；短停 0.25s；「國際」放慢、一字一頓，「際」去聲落地乾淨收尾，不拖、不揚。
```

- 三句的**音高走勢**：第一句開展（中→高），第二句沉穩（高→低），第三句定音（中→低，最堅定）。不是遞增激昂，而是「起—承—定」。
- 整段總長目標 6.5–7.5s，依實測調整片尾字幕；**不加速、不裁字**。

## 3. 生成參數（MiniMax，沿用已批准的克隆聲線 BOI-HK-v13-R06-Clone-r01）

- **不加任何情緒標記**（不用 Happy）；若需選，只可試 `calm` 或 neutral。
- speed **0.80–0.85**，pitch **−1 或 0**（禁止正值），volume 1。
- **逐句分開生成**，每句三個變體，共 9 條：
  - A：speed 0.82 / pitch −1 / 無情緒
  - B：speed 0.85 / pitch 0 / 無情緒
  - C：speed 0.80 / pitch −1 / calm
- 用標點與停頓標記引導節奏，不靠後期拉伸。例如：
  - `大展——宏圖。`
  - `穩如，泰山。`（逗號只為讓「泰山」重起，若生成出現明顯斷句感則改回 `穩如泰山。`）
  - `宏泰，國際。`
- **禁止**對任何字做 WSOLA／time-stretch。長音必須是生成本身的自然延長。若「山」不夠長，換變體或改標點重生，不後期拉。
- 生成前先估點數並回報；**先只生成第一句「大展宏圖」的 3 個變體給使用者試聽**，確認方向後再生成其餘兩句，避免浪費點數。

## 4. 拼接與後期

- 三句各選一條最佳 take，按第 2 節停頓拼接；接點 10ms 交叉淡化，落在靜音處。
- 胸腔厚度：低架 80Hz 以下切除，150–250Hz 輕提 +1.5dB，3–5kHz 不提亮（避免尖）。
- 空間：極輕的大廳殘響（RT60 ≈1.2s，濕度 ≤8%），只在「山」「際」的尾巴聽得出來，營造殿堂感；不得聽出明顯回聲。
- 力度：三句響度相近（±1LU），**不做遞增**；靠音高和停頓分層次。
- 配樂：「穩如泰山」後的 0.9s 留白處，配樂可同步一個低音落點（若原曲在此附近有重拍則對齊；沒有則不加新音效）。品牌名「宏泰國際」說完後配樂收尾按原有淡出。
- 整段 −16 LUFS ±0.5，true peak ≤ −1 dBTP。

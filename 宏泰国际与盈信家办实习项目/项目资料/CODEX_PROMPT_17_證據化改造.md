## 1. 診斷：為什麼單調

我把四帧並排看，問題不在色彩、不在字體，而在**四帧共用同一個骨架**：

```
小標（字距鬆開的英文大寫）
＋ 襯線大標
＋ 一條細線
＋ 單色小字
```

四段都是這個結構，只有內容換了。觀眾看第一段覺得克制，看第二段覺得安靜，看第三段就開始覺得空，第四段會覺得這是一份沒做完的 PPT。

具體三個毛病：

**毛病一：右半邊是空的。**
S3 的數字全擠在左側 60%，右側 400px 完全空白。S4 的評級卡也只佔左側。空白本身不是問題，**但沒有理由的空白會被讀成「還沒做完」**。

**毛病二：全部是文字，沒有一張實物。**
四段加起來，出現的東西只有字和線。**文字只能「宣稱」，不能「證明」**。你說 A 級以上、說有三個辦公室，觀眾沒有辦法相信，因為畫面裡沒有任何可以「看見」的東西。

**毛病三：資訊之間沒有層級差。**
S3 三個數字一樣大、間距一樣；S4 三個評級卡一樣大。平等的排版等於沒有重點。

- ✅ **地圖部分可裁切使用**（約 450×600 的區域，作為圖形元素，不超過 600px 寬）
- ❌ **單張城市照不可全屏**
- ❌ **不可整張 1770×1181 直接貼進來**（那個深色底板 + 中文字幕條是 PPT 的視覺，不是我們的）

若要逐州展示，需另找授權圖庫照片，本輪不做。

## 3. 核心解法：證據要用「檔案」的語言，不是「目錄」的語言

使用者擔心「有了實例就不美」。這個擔憂是對的，但原因不是照片本身難看，而是**呈現方式選錯了**。

### 3.1 兩種錯誤的做法

**錯誤 A：把它當廣告素材用。**
照片全屏、加暗角、加大字壓在上面、配漸層遮罩。這是地產廣告的做法。結果是「廉價」，而且會讓美國觀眾立刻想起那種賣樓的片子。

**錯誤 B：把它當插圖用。**
在小標旁邊放一張 120×120 的小圓圖。結果是「PPT 圖標」，比現在更糟。

### 3.2 正確的做法：檔案感（dossier）

把整支片當成一份**可以被人拿在手裡翻閱的檔案**，而不是一則廣告。具體四條規則：

**規則一：每張照片都配「圖注」，不配「標語」。**

```
┌──────────────────┐
│                  │
│     [實景照片]     │
│                  │
└──────────────────┘
FIG. 02 — Flushing, New York
```

圖注是 14px、`muted`、字距 .08em，**放在照片下方左對齊**，不放中間、不放大。

這個「FIG. 0X」編號是關鍵——它宣告「這是一份有編號的證據清單」，觀眾會自動把它當文件讀，而不是當廣告看。**檔案感就是美感的來源**。

**規則二：照片一律不圓角、不陰影、不加濾鏡。**

- 直角矩形，1px `line` 色細邊框（或完全無框，全出血）
- 統一套用與人物卡**完全相同**的調色（降飽和 + ink 色調 + 輕微暖偏移）
- 這是讓「新照片」與「舊人物卡」看起來出自同一份檔案的方法

**規則三：一張照片只能證明一件事。**
不要在一張照片上疊三個說明。照片證明「這裡有一個真實的辦公室」，數字證明「規模」，兩者分開放在同一帧的不同位置，中間留白。

**規則四：允許不對齊。**
不要每帧都居中對齊。S3 可以左重右輕，S4 可以下方滿出血。**一致的骨架才是單調的根源**，打破骨架比換內容更能解決問題。

## 4. 逐段改造方案

> 所有改動必須在現有時間軸內完成，**不得延長或縮短任何一段**。

### 4.1 S1｜我們是誰（8.10s）

**現狀**：文字堆在左中，下方大片空白，右下是雙語字幕。

**改法**：改為**左右分欄**。

- **左欄（0–760px）**：保留現有文字結構（Blue Oak International / Hong Kong · United States / 細線 / Group heritage since 1997.），但整體上移 40px，給下方圖注留位。
- **右欄（900–1776px）**：放一張辦公室實景，**4:3 直式裁切，寬 620px**。
  - 建議用 `hk-main.png`（1613×1210，倍率 0.38，綽綽有餘）或 NY 前台那張。
  - 照片下方加圖注：`FIG. 01 — Hong Kong`。
- 照片入場：由右向左推入 24px + opacity，0.6s，比文字晚 0.3s。

**為什麼**：S1 是「我們是誰」，最需要一個「你確實存在」的視覺錨點。一張真實的前台照片比任何形容詞都有效。

### 4.2 S3｜規模（10.13s）— 改動最大

**現狀**：三個數字擠在左側，右側 400px 全空。

**改法**：改為 **三大數字 + 右側一條垂直照片帶**。

- **左區（0–1100px）**：三個數字保持現在的排版（HK$ 10B+ / HK$ 1.5B+ / 3），但**加大行間距**，讓三段撐滿垂直空間（現為 228px 間距，改為 268px）。
- **右區（1180–1776px）**：**三張辦公室照片縱向排列**，每張 596×196（寬高比約 3:1 橫幅裁切），間距 32px。
  - 順序：Hong Kong / Shenzhen / New York
  - 每張下方極小圖注：`FIG. 02 / FIG. 03 / FIG. 04`
  - **這三張照片與左側三個數字不是一一對應**——數字是保費、佣金、辦公室數，照片是三地辦公室。**不要用連線把它們綁在一起**，那只會誤導。
- 三張照片比數字晚 0.4s 出現，由下往上錯開 8 幀。

**為什麼**：「3 offices」如果只是文字，是一個說法；配上三張真實空間照片，它變成事實。

**若三張橫幅裁切後清晰度不足**（`hk-lower.png` 僅 796×430，裁 3:1 後約 796×265，放 596×196 倍率 0.75，**可用**），但 `ny-main.jpg` 851×638 裁 3:1 後 851×284，放 596×196 倍率 0.70，**可用**。三張都能用，不必換。

### 4.3 S4｜門檻（7.73s）— 最需要「實證感」的一段

**現狀**：三張評級卡並排，像一個圖例；「9 states」只是一行字。

**改法**：**把「9 states」從文字變成地圖**，這是本段最大的改進。

- **上半部（y 130–520）**：保留評級卡，但**縮小到 360×200**，三張並排靠左，右側留白。卡內只保留 `A++` / `A+` / `A` 與 `Superior` / `Excellent`，**移除**「Company-reported selection standard」這行小字（它出現在三個地方，重複且削弱信心）。
- **下半部（y 560–940）**：放**美國地圖**，從 PDF P13 內嵌圖裁出（約 450×600 的區域），**寬度不超過 520px**，置於畫面**右側**，左側配文字：
  - `Products across 9 states.`（28px）
  - 下方一行州名，用極小字（14px、`muted`、分兩行）：
    `California · New York · Massachusetts · Arizona · Connecticut`
    `Texas · North Carolina · Delaware · New Jersey`
  - **這行州名很重要**——地圖只能給「範圍感」，具體州名才是可查證的資訊。
- 地圖處理：**去掉深色底板與中文字幕條**，只保留地圖輪廓與 9 個點；顏色改為 `line` 色描邊 + `terracotta` 點位，與全片語言一致。

**為什麼**：現在「9 states」是抽象數字，改成地圖後觀眾立刻知道「哦，是這九個州」。而且地圖是可辨識的美國輪廓，這對美國觀眾是極強的本土信號。

**⚠️ 若地圖裁切後清晰度不足**：退化為只保留州名列表（不加地圖），**不要放大模糊的地圖**。模糊的地圖比沒有地圖更糟。

### 4.4 S5｜基礎設施（11.80s）

**現狀**：2×2 四格純文字，最單調的一段。

**改法**：四格改為 **2×2，但只有一個格里放照片**。

- **左上格**（Flushing, New York）→ 換成**紐約辦公室實景**，照片 640×280，下方圖注 `FIG. 05 — Flushing, New York`。
- **右上 / 左下 / 右下**三格保持文字，但**改為無邊框**，只用細線分隔，與照片形成材質對比。
- 四格不再等大：左上（照片）佔 2 欄寬，其餘三格在右側與下方。

**更簡的替代方案**（若排版過於複雜）：四格全保留文字，但把左上格的照片作為**背景**，壓到 opacity 0.14，文字置於其上。這樣既有實物感又不破壞結構。

**推薦前者，替代方案作為 fallback。**

## 5. 時間與動效（不得突破）

| 段 | 現有時長 | 新增元素的入場時間 |
|---|---|---|
| S1 | 8.10s | 照片晚於文字 0.3s，0.6s 完成 |
| S3 | 10.13s | 三張照片各錯開 8 幀，最後一張於旁白念到 "three offices" 前完成 |
| S4 | 7.73s | 地圖於念到 "nine states" 時淡入，2 秒完成描邊繪製 |
| S5 | 11.80s | 照片於 `FIG. 05` 對應內容出現時入場 |

**統一動效語言：**

- 照片：`opacity 0→1` + `translateY 12px→0`，0.5s，`theme.ease`
- 地圖：描邊用 `stroke-dashoffset` 由 0 繪到全長，2s，**不做逐點彈跳**
- 禁止：Ken Burns 推鏡、視差、粒子、光暈、模糊轉場

## 6. 調色規格（所有新增照片必須一致）

```
飽和度    ×0.55
亮度      ×0.96
對比度    ×1.02
疊色      ink 色 #3d3833，混合模式 multiply，opacity 0.10
暖色偏移  +2（R），−1（B）
```

**目的**：讓 2026 年拍的辦公室照片與 2025 年拍的證件照、與紙色背景，看起來像同一份檔案裡的三種材料，而不是三個來源的拼貼。

**驗收方式**：四段截圖並排，照片區域的**平均色溫**應落在 ±150K 內；不得有明顯偏藍或偏黃的照片。

## 4. 動效：焦點手風琴

### 4.1 版式（1920×1080，米白底 `#F4EEE2`）

```
y 120     段落標題「專業，由人而來」 48px，x=130（入場後固定不動）
照片列    x 130–1790，y 260–900，6 張竖幅，間距 8，無圓角、無邊框、無陰影
靜止態    6 張等寬（約 270px），灰階 100%，透明度 0.55
聚焦態    當前 flex 4 份（約 900px），彩色，透明度 1
          其餘 5 張平分剩餘寬度（約 145px），灰階，透明度 0.55
功績區    照片列下方 y 920–1010 的獨立文字帶，與照片 bounding box 永不相交
          姓名 44px（Instrument Serif / 思源宋體）· 職銜 20px 朱砂 #B9653F
          功績三項橫排，以「·」分隔，20px #41596B
```
（文字帶左緣對齊聚焦照片左緣，隨聚焦照片位置平移，平移曲線與照片同步。）

### 4.2 聯動曲線

- 寬度、灰階、透明度、照片內 scale（1.04→1.00）**共用同一條時間曲線**：500ms，`cubic-bezier(0.16,1,0.3,1)`。
- 不得逐張錯開、不得彈性、不得超過 600ms。
- 寬度用 flex-grow 插值計算後**取整到 1px**，總寬恆定 1660px，任何一幀不得溢出或留縫（寫腳本驗證）。

### 4.3 每人節奏（2.4s / 72 幀）

| 時間 | 動作 |
|---|---|
| 0.00s | 舊文字上移 12px 淡出，200ms |
| 0.20s | 照片聯動切換，500ms |
| 0.32s | 新姓名 → 職銜 → 功績，逐行上浮 12px 淡入，各 300ms，錯開 80ms |
| 0.90–2.40s | 完全靜止 |

同一時間只有一個主角在動：文字先走、照片再動、新文字最後到。

### 4.4 合照牆收束（約 3s）

- 6 張先同時回到等寬靜止態（500ms），再整列向上淡出 24px。
- 5 位美國高級合夥人以一排 5 張等寬（各 300×400）由下升入，錯開 3 幀，下方各一行姓名 18px + 「美國高級合夥人」14px。
- 最後一句旁白期間靜止，接原有「根扎得深」鏡的轉場。

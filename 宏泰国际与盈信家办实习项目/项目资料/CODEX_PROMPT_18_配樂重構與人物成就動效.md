## 1. 配樂：先說清楚它為什麼平

### 1.1 實測診斷（不是主觀判斷）

我把 `public/music/us-v1/ASSET_ROLES.json` 裡的樂譜完整算了一遍：

| 指標 | 實測值 | 問題 |
|---|---|---|
| 音符總數 | **42 個 / 60 秒** | 平均 1.4 秒一個音，且多數時間是空的 |
| 單音時長 | 全部 **5.2 秒** | 每個音都拖得很長，且完全一致 |
| 音符間隔 | 全部 **3.7 秒** | 節奏完全機械，沒有任何節奏變化 |
| **同時發聲音數** | **最大 1** | **全曲是單音旋律，沒有和聲、沒有低音、沒有織體** |
| 音域 | MIDI 48–64，**僅 1.3 個八度** | 過窄，聽起來像練習曲 |
| 樂器 | 合成柔鍵盤，非錄音鋼琴 | 音色偏薄 |

**結論：它不是「安靜」，是「空」。** 一首只有單線旋律、沒有低音支撐、沒有和聲舖底的曲子，無論音量調多大都會顯得平。你現在聽到的平淡，根源在**織體（texture）**，不在音量。

### 1.2 改造方向：保留極簡，補上骨架

**不要換成弦樂，也不要加鼓。** 使用者的方向是對的，只是執行時缺了三層。改造原則是**「極簡，但要完整」**：

| 層 | 現狀 | 要加的 |
|---|---|---|
| **低音層（Bass）** | 無 | 每 2 小節一個長音，MIDI 36–43（C2–G2），音量比旋律低 8 dB |
| **和聲層（Pad）** | 無 | 每 4 小節一組三音和弦，MIDI 48–67，極慢 attack（1.2s），音量比旋律低 12 dB |
| **旋律層（Melody）** | 有（42 音） | 保留，但**音長由固定 5.2s 改為 2.4–4.8s 不等**，間隔由固定 3.7s 改為 2.2–4.1s |
| **節奏層（Pulse）** | 無 | **不加鼓**。但在 S3 數字段加一層極輕的低頻脈衝（每 2 拍一次，-30 dB），只在該段出現 |

**關鍵：低音與和聲只做「墊底」，不搶戲。** 觀眾不應該「聽到」低音，但拿掉之後會立刻覺得虛。這就是骨架的作用。

### 1.3 和聲進行（照此使用）

**4 小節一循環，共 15 個循環 = 60 秒。** 用 A 小調，暗而不悲，適合金融題材：

```
Am — F — C — G
```

MIDI 具體音（每個和弦保持 4.8 秒，重疊 0.4 秒交叉淡入）：

| 和弦 | 三音（Pad） | 低音（Bass） |
|---|---|---|
| Am | 57, 60, 64 | 45 |
| F | 53, 57, 60 | 41 |
| C | 55, 60, 64 | 48 |
| G | 55, 59, 62 | 43 |

**旋律層在這些和弦內自由走**，只用和弦內音 + 經過音，不要出現和弦外的不協和音。

### 1.4 動態曲線（這是「不平淡」的真正來源）

不要全曲一個音量。按段落做動態：

| 段 | 幀 | 音樂狀態 |
|---|---|---|
| S0 開場 | 0–120 | **完全靜音**（保持現狀，這是對的） |
| S1 身份 | 120–363 | 只有 Pad + Bass，**旋律不進**。音量 -20 dB |
| S2 人物 | 363–603 | 旋律進入，Pad 提升。-16 dB |
| S3 規模 | 603–907 | **全片最飽滿**：三層全開 + 低頻脈衝。-13 dB |
| S4 門檻 | 907–1139 | 撤掉脈衝，Pad 保留。**在念到 "nine states" 時做一次 0.6s 的短促上揚** |
| S5 基礎設施 | 1139–1493 | 降回 -18 dB，只留 Pad + Bass |
| S6 最難的一年 | 1493–1583 | **全靜**（保持現狀，這是對的） |
| S7 收尾 | 1583–1800 | 旋律回歸，最後 1.5s 自然收束（不要突然斷） |

**S3 是全片唯一允許音樂稍微上前的段落**，這一條與 `CODEX_PROMPT_15` 一致。

### 1.5 技術規格

- 生成方式：沿用現有 `scripts/mix-us-full-v2.py` 的加法合成法，**不引入任何外部音源**。
- 新增 `scripts/generate-us-score-v2.py`，輸出 `public/music/us-v2/original-score-v2.wav`（48kHz / 立體聲 / 未壓縮）。
- **樂譜需完整寫入 `ASSET_ROLES.json`**（每個音的 time / midi / duration / layer / gainDB），保證可復現。
- 人聲 duck 規格不變：-18 dB，0.5s 回復。
- **BGM 峰值仍須比旁白低 ≥ 12 dB**。
- 全片峰值 ≤ -1 dBFS。

### 1.6 驗收（可量化，不要憑感覺）

- [ ] 同時發聲音數：全片平均 ≥ 3（現為 1）
- [ ] 低音層存在：40–50 Hz 頻段能量比現版本高 ≥ 6 dB
- [ ] 動態範圍：S3 與 S5 的音量差 ≥ 5 dB
- [ ] 旋律音長不再全部相同（至少 3 種不同長度）
- [ ] 無鼓組、無弦樂、無 riser

## 2. S1 開場：加入 Logo，但要「生長」而不是「貼上」

### 2.1 現狀問題

截圖裡 S1 左邊是文字，右邊是前台照片，**品牌標誌完全缺席**。一支 60 秒的品牌片，到第 8 秒還沒有出現 Logo，是結構性缺失。

但**不要**把 Logo 放在畫面中央然後放大——那是房地產廣告的做法。

### 2.2 方案：Logo 在左欄上方，以線條繪製方式入場

**版面：**

```
y 150  ┌─────────────────┐
       │  [橡樹線稿]      │   ← 寬 88px，只有樹，無字標
       └─────────────────┘
y 300  Blue Oak
       International.        ← 現有襯線大標，位置不變
```

**為什麼只畫樹、不帶字標：** 底下已經有 `Blue Oak International.` 的文字，再放一次官方字標會重複。**樹是符號，字是名稱，分開用。**

### 2.3 動效：由下往上的「生長」，不是淡入

時間：S1 開始後 0–1.6 秒。

1. **0–0.5s**：底座橫線由中心向兩側展開（`scaleX 0→1`）
2. **0.4–1.0s**：樹幹由下往上生長（`clipPath` 自下而上）
3. **0.8–1.6s**：樹冠葉片由內圈到外圈逐片出現，每圈錯開 0.12s
4. 完成後**保持靜止**，不再動

**這一招與片尾 S7 的完整 Logo 生長動效同源**，形成首尾呼應。但 S1 這版要**快**（1.6s vs 片尾 4.2s），因為 S1 有旁白要讀。

### 2.4 顏色

**必須使用官方原色**（`#004098` / `#0051a4` / `#007bc7` / 樹幹漸層），不可用 `currentColor`。

若擔心藍色在淺米底上太跳：**降 opacity 到 0.85，不要改色值。** 這是本片的品牌錨點，也是全片唯一的藍。

### 2.5 實作

- 複用 `OfficialBrandV10` 的 `draw()` 與分組結構（`trunk` / `base` / `canopy > ring-N`）。
- 但**不渲染 `chinese` 與 `english` 分組**（字標），只畫樹。
- 縮放至 88px 寬，置於 `left: 256, top: 150`。
- `prefix` 傳 `'us-s1'`，避免 gradient id 衝突。

## 3. S2 人物鏡：成就展示動效

### 3.1 先說清楚一個限制

使用者要「展示每個人的一些成就」。但現有資料只有 PDF 的 `Formerly at XXX` 一行。**我沒有更多成就資料，不能編。**

所以設計必須做到兩件事：

1. **現有資料能支撐的形式**（前雇主、學歷、年資）
2. **日後補資料時能直接套用**（結構可擴充）

### 3.2 三個方案，推薦第二個

**方案 A（不推薦）：hover 式浮出**
每張卡片旁邊浮出一行成就。問題：影片不是網頁，觀眾不知道要看哪裡，會漏掉。

**方案 B（推薦）：逐張「聚焦」序列**
把 8 秒切成 6 個 1.2 秒的節拍，**每次只有一張卡片被「點亮」**，其餘五張壓暗。被點亮的卡片輕微放大 1.04，並在其右側展開一行成就文字。

**方案 C：全部同時展示**
六張卡片同時顯示成就。問題：六行小字同時出現，資訊過載，且違背「簡約」。

**選 B。** 理由：它創造了**視覺節奏**（觀眾會跟著一張一張看），而且天然適合「每個人一句話」的結構。

### 3.3 方案 B 的具體規格

**版面**：維持現有 3×2 網格，卡片 224×280，位置不動。

**聚焦序列**：

| 時序 | 卡片 | 動作 |
|---|---|---|
| 0–0.4s | — | 六張全部淡入（現有動效，保留） |
| 0.4–1.6s | David Wang | 其餘壓至 opacity 0.35 + 去飽和；此張 1.04 倍，右側展開成就 |
| 1.6–2.8s | Lily Ku | 同上 |
| 2.8–4.0s | Noah Cheung | 同上 |
| 4.0–5.2s | Catherine Luo | 同上 |
| 5.2–6.4s | Vivian Mau | 同上 |
| 6.4–7.4s | Crystal Wan | 同上 |
| 7.4–8.0s | — | 全部恢復正常亮度，淡出 |

**成就文字的呈現（這是高級感的關鍵）：**

不要用「標籤」，用**極簡的資訊行**：

```
David Wang                ← 現有，襯線 24px
US General Manager        ← 新增，無襯線 13px，muted，字距 .08em
Formerly at WFG           ← 現有
20 years in financial services   ← 新增，13px，muted
```

- 文字**由左向右逐字淡入**（不是整段淡入），每字間隔 12ms。這是「打字機」的剋制版本，比整段淡入有質感。
- 文字顏色 `muted`，**不要用 terracotta 或藍色**。重點靠位置和對比度，不靠顏色。
- 高度限制：最多 2 行成就，超出刪減。

**聚焦的方式（避免廉價感）：**

- 壓暗用 `opacity` + `filter: saturate()`，**不要用模糊**。
- 放大 1.04 時 `transition` 用 `theme.ease`，0.4s。**不要用彈跳。**
- 不做陰影、不做描邊、不做光暈。
- 被聚焦的卡片可加一條 **1px 的底部細線**（`terracotta`，寬度由 0 展開到卡片寬度），這是唯一的色彩點綴。

### 3.4 成就資料（現有可用的）

**我只能用 PDF 裡有的。** 以下是可用的部分：

| Catherine Luo | 18 年金融資歷；曾任德意志銀行、蘇格蘭皇家銀行高級職務 |
| Vivian Mau | CUNY City College 電腦科學碩士；曾任 WFG、PFA 資深經理 |

## 4. 「實際的展示，但要簡單且有藝術設計」

這一條對應 `CODEX_PROMPT_17` 的照片與地圖改造，**本輪不重複**。但補一條原則，適用於所有素材：

> **一張照片 + 一行圖注 = 證據。**
> **兩張照片 + 一段說明 = 廣告。**
> **三張以上 = 圖庫。**

寧可少放，也不要堆。每個段落**最多一張主要視覺**。
